# 기하 개념 탐구 실험실

2022 개정 교육과정 〈기하〉(진로 선택)의 성취기준 14개를 17차시 개념기반 탐구로 엮은 학습용 웹앱입니다. 같은 사이트의 [공통수학](../math1/), [대수](../algebra/), [미적분Ⅰ](../calculus1/), [미적분Ⅱ](../calculus2/), [확률과 통계](../prob-stats/) 개념 탐구 실험실과 같은 틀(5단계 탐구, 수학 노트, PDF 저장, G-Man 멘토, 개인정보 처리방침)을 쓰고, 내용과 탐색 도구만 〈기하〉로 바꾸었습니다. 기하의 특성에 맞추어 10개 차시에 **끌어서 돌려 보는 3D 입체 화면**을, 11개 차시에 **🧪 무작위 실험**(1번, 10번, 100번, 1000번 반복과 계속 실험하기)을 넣었습니다.

주소: [gabrielmath.kr/geo](https://gabrielmath.kr/geo/)

| 단원 | 차시 | 성취기준 |
|---|---|---|
| Ⅰ. 이차곡선 | 포물선, 타원, 쌍곡선, 원뿔을 자르면 보이는 곡선(통합), 이차곡선의 접선, 반사 성질 | 12기하01-01~04 |
| Ⅱ. 공간도형과 공간좌표 | 위치 관계, 삼수선 정리, 정사영과 이면각, 좌표공간과 두 점 사이의 거리, 내분점, 구의 방정식 | 12기하02-01~05 |
| Ⅲ. 벡터 | 벡터와 그 연산, 위치벡터와 성분, 내적, 벡터로 나타낸 직선, 평면과 구의 벡터방정식 | 12기하03-01~05 |

## 각 차시의 구성

질문하기(핵심 질문, 배우기 전 예상) → 탐색하기(탐색 도구와 실험, 사실적 질문) → 개념화하기(개념적 질문, 나의 일반화, 멘토 피드백, 교사용 일반화, 개념 정리) → 적용과 전이(채점되는 적용 문제 3개, 전이 과제, 논쟁적 질문) → 성찰하기

## 탐색 도구와 실험 (17개 차시)

- **이차곡선:** 초점과 준선 조작판(평행이동 포함), 두 초점과 실로 그리는 타원, 거리의 차와 점근선, 🧪 무작위 점으로 포물선·타원·쌍곡선의 자취 찾기, 3D 원뿔을 평면으로 자르기(원·타원·포물선·쌍곡선), 일반형 방정식을 완전제곱식으로 바꾸는 분류기, 직선을 움직이며 판별식 확인하기, 곡선 위의 점에서의 접선, 🧪 접선 모아 곡선 만들기, 🧪 포물선·타원·쌍곡선 거울에 광선 쏘기
- **공간도형과 공간좌표:** 3D 정육면체에서 직선과 평면의 위치 관계(교점, 교선, 꼬인 위치의 각), 🧪 두 모서리를 무작위로 고르기, 3D 삼수선 정리, 🧪 무작위 상황에서 두 각 재기, 3D 선분과 평면도형의 정사영과 이면각, 🧪 무작위 삼각형으로 넓이의 비 실험, 3D 좌표공간의 점과 대칭이동, 두 점 사이의 거리 상자, 내분점과 무게중심, 3D 구와 단면, 전개한 방정식에서 중심과 반지름 찾기, 🧪 공간에 점을 찍어 구 찾기
- **벡터:** 끌어서 바꾸는 화살표로 덧셈·뺄셈·실수배·일차결합, 위치벡터와 내분점, 3D 공간벡터의 성분, 내적과 정사영, 🧪 무작위 벡터로 두 계산법 비교, 방향벡터와 법선벡터로 나타낸 직선, 3D 공간의 직선, 3D 법선벡터로 평면 만들기, 구의 벡터방정식, 🧪 수직 조건만 남기는 점 실험

3D 화면은 끌어서 돌리고, 단추로 ‘처음 시점’, ‘위에서 보기’, ‘돌리기’, 확대와 축소를 할 수 있습니다. 외부 3D 라이브러리 없이 앱 안의 캔버스로 그립니다.

## 교육과정 범위

교육과정의 ‘성취기준 해설’과 ‘성취기준 적용 시 고려 사항’에 맞추었습니다. 이차곡선은 축이 좌표축에 평행한 것만 다루고, 이심률을 이용한 정의는 넣지 않았습니다. 이차곡선과 직선의 관계는 접하는 경우만 다루며, 접선은 판별식으로 구하고, 평행이동한 이차곡선의 접선은 다루지 않습니다. 공간도형의 성질은 3D 화면에서 관찰한 뒤 개념적 질문에서 증명하게 하고, 공간좌표는 평면좌표를 확장하는 수준에서 다룹니다. 벡터를 이용한 도형의 방정식은 도형을 벡터로 표현할 수 있음을 이해하는 수준에서 다루며, 지나치게 복잡한 공간지각력을 요구하는 문제는 넣지 않았습니다. G-Man 멘토에도 같은 범위를 지키도록 지시되어 있습니다.

## 실행

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 수식 표시 도구(KaTeX, MathJax)가 파일 안에 들어 있어 크기가 약 2.7MB입니다. 실험의 난수는 브라우저 안에서 만들며, 결과는 매번 달라집니다.

## 저장과 개인정보

- 학습 기록은 `geo-inquiry-lab-v1` 이름으로 이 기기의 브라우저에만 저장되며, math1, algebra, calculus1, calculus2, prob-stats의 기록과 섞이지 않습니다.
- G-Man 멘토 API 키 설정(`gman-mentor-key-v1`)은 같은 도메인의 다른 웹앱과 함께 씁니다. 한 번 넣으면 모든 앱에서 작동합니다.
- 자세한 조항은 [PRIVACY.md](./PRIVACY.md)에 있습니다.

## 내용의 출처

- 교육과정: 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 (기하)의 성격, 목표, 핵심 아이디어, 성취기준, 성취기준 해설, 성취기준 적용 시 고려 사항, 교수·학습 방법
- 교과서: 이 판은 교과서를 참고하지 않고 교육과정 성취기준만으로 구성했습니다. 차시마다 ‘교육과정 성취기준 기반 자체 구성’으로 표시되며, 교과서 쪽수는 표시하지 않습니다.
- 탐색 상황, 수치, 적용 문제 51개는 모두 성취기준을 바탕으로 새로 만든 자체 제작입니다.
