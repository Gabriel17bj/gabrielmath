# gabrielmath.kr

수학 교육용 웹앱 사이트. GitHub Pages로 배포.

| 주소 | 폴더 | 내용 |
|---|---|---|
| gabrielmath.kr | / | 웹앱 목록 (메인) |
| gabrielmath.kr/math1/ | math1/ | 공통수학 개념 탐구 실험실 |

## 새 웹앱 추가
1. 새 폴더 생성 (예: math2) → 그 안에 웹앱 파일을 index.html 이름으로 저장
2. 루트 index.html 의 웹앱 목록에 <li> 한 덩어리 복사·수정
3. GitHub에 업로드(커밋) → 1~2분 뒤 gabrielmath.kr/math2/ 에서 확인
