# 공통수학 개념 탐구 실험실

2022 개정 교육과정 〈공통수학1〉과 〈공통수학2〉의 성취기준을 개념기반 탐구 차시로 엮은 학습용 웹앱입니다. 학생이 공식을 외우기 전에 도구를 직접 움직여 사실을 모으고, 그 사실을 ‘왜’로 연결해 자기 문장으로 개념을 정리하도록 설계했습니다.

- 〈공통수학1〉 10차시: 다항식, 방정식과 부등식, 경우의 수, 행렬 (성취기준 14개)
- 〈공통수학2〉 9차시: 도형의 방정식, 집합과 명제, 함수와 그래프 (성취기준 20개)

## 주요 기능

| 기능 | 내용 |
|---|---|
| 5단계 탐구 | 질문하기 → 탐색하기 → 개념화하기 → 적용과 전이 → 성찰하기 |
| 세 층위 질문 | 사실적 질문, 개념적 질문, 논쟁적 질문 |
| 탐색 도구 | 넓이 모델, 조립제법과 그래프, 판별식과 근 추적, 벤 다이어그램, 진리집합, 화살표 대응도, 행렬 거듭제곱 등 |
| 수식 표시 | LaTeX로 쓴 수식을 수학 글꼴로 표시 (MathJax, 안 되면 KaTeX) |
| 수학 노트 | 기호 단추로 LaTeX 수식을 넣고 바로 미리보기 |
| 기록 저장 | 학생의 예상, 일반화, 문제 답, 성찰, 노트를 PDF로 저장하거나 인쇄 |
| G-Man 멘토 | 정답 대신 질문으로 생각을 이어 주는 AI 학습 도우미 (claude.ai에서는 바로, 그 밖에서는 여러 AI 회사의 API 키로 동작, 그림 설명서 제공) |
| 교사용 안내 | 성취기준과 차시, 탐구 도구, 평가 관점 연결표 |

## 실행 방법

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 수식 표시 도구(KaTeX, MathJax)가 파일 안에 들어 있어 크기가 약 2.6MB입니다.

- **내 컴퓨터에서:** `index.html`을 브라우저로 엽니다.
- **GitHub Pages로 공개:** 저장소의 Settings → Pages에서 Source를 `Deploy from a branch`, Branch를 `main`과 `/ (root)`로 고릅니다.

### 실행 환경에 따른 차이

| 기능 | claude.ai 게시 화면 | GitHub Pages, 내 컴퓨터 |
|---|---|---|
| 탐구 차시, 수식, 수학 노트 | 사용 가능 | 사용 가능 |
| PDF 저장 | 저장 확인 창으로 저장 | 브라우저의 일반 다운로드로 저장 |
| G-Man 멘토 | 키 없이 사용 가능 | AI 회사의 API 키를 넣으면 사용 가능. 키가 없으면 아무것도 보내지 않음 |

## G-Man 멘토와 AI 열쇠(API 키)

G-Man 멘토는 정답 대신 힌트와 질문으로 도와주는 AI 학습 도우미입니다. 앱의 **‘G-Man 멘토 그림 설명서’** 화면에 학생용 그림 안내(8단계)가 있고, PDF로 저장하거나 인쇄할 수 있습니다.

| 앱을 연 곳 | 필요한 것 |
|---|---|
| claude.ai 게시 화면 | 없음 (바로 사용) |
| gabrielmath.kr, GitHub Pages, 내 컴퓨터 | AI 열쇠(API 키) 한 번 입력 |

쓸 수 있는 열쇠는 다음과 같습니다. 열쇠 모양을 보고 회사를 자동으로 알아봅니다.

| 회사 | 열쇠 받는 곳 | 열쇠 모양 |
|---|---|---|
| Anthropic (Claude) | console.anthropic.com | `sk-ant-…` |
| OpenAI (ChatGPT) | platform.openai.com | `sk-…` |
| Google (Gemini) | aistudio.google.com | `AIza…` |
| OpenRouter (여러 AI) | openrouter.ai | `sk-or-…` |
| Groq | console.groq.com | `gsk_…` |
| xAI (Grok) | console.x.ai | `xai-…` |
| 그 밖의 회사 | 직접 입력 (OpenAI 호환 주소) | 회사마다 다름 |

- 열쇠를 넣으면 그 회사에 **사용 가능한 모델 목록을 물어 알맞은 모델을 자동으로 고릅니다.** 모델 이름이 바뀌어도 계속 작동하도록 한 것이며, ‘고급 설정’에서 바꿀 수 있습니다.
- 열쇠는 기본으로 지금 연 탭에만 보관되고 탭을 닫으면 지워집니다. ‘이 컴퓨터에 기억하기’를 고를 때만 브라우저 저장소에 남습니다.
- 열쇠는 이 브라우저에서 해당 AI 회사의 API 주소로만 보내지며, 운영자 서버를 거치지 않습니다. 회사에 따라 웹 페이지에서 바로 연결하는 것을 막을 수 있습니다.
- 사용 요금은 열쇠 주인의 계정에 청구됩니다. 사용 한도를 낮게 정해 두세요.
- **API 키를 `index.html`이나 저장소에 적지 마세요.**

## 내용의 출처

외부 자료에서 가져온 내용은 앱 화면의 문항마다, 그리고 각 차시의 ‘질문하기’, ‘적용과 전이’ 단계에 출처를 표시했습니다. 전체 목록은 [docs/SOURCES.md](./docs/SOURCES.md)에 있습니다.

- **교육과정:** 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 (핵심 아이디어, 성취기준)
- **교과서:** 미래엔 〈공통수학1〉 교과서 (〈공통수학1〉 적용 문제 22개 중 20개와 일부 탐색 상황, 문항마다 쪽수와 번호 표시)
- **정답 및 풀이:** 미래엔 〈공통수학1〉 교과서 정답 및 풀이 (교과서 문항의 정답과 풀이 참고, 문항마다 쪽수 표시)
- **자체 제작:** 〈공통수학2〉 전체, 〈공통수학1〉 적용 문제 2개

> **공개 전 확인:** 출처를 밝혀도 교과서 문항을 공개 저장소에 그대로 싣는 것은 출판사의 이용 허락이 필요할 수 있습니다. 공개 전에 출판사 이용 조건을 확인하거나 해당 문항을 자체 문항으로 바꾸는 것을 권합니다.
