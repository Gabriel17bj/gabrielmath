# 개인정보 처리방침

**수능형 문항 출제실 (교사용 · 개인정보 미수집)**

앱 화면 하단의 ‘개인정보 처리방침’을 누르면 같은 내용을 팝업 창으로 볼 수 있습니다. 처음 방문할 때에는 ‘출제 주의 사항’과 개인정보 처리 안내를 담은 사용 전 안내 팝업이 함께 표시됩니다.

수능형 문항 출제실(이하 ‘이 앱’)은 교사가 2022 개정 교육과정 성취기준에 따라 수능형 연습 문항을 만들고 인쇄·저장하도록 돕는 웹 애플리케이션입니다. 이 앱은 이용자의 개인정보를 수집하거나 운영자의 서버에 전송·저장하지 않습니다. 회원가입이나 로그인 없이 쓸 수 있으며, 입력한 내용은 이용자의 기기(브라우저 저장소)에만 보관됩니다. 이 앱은 「개인정보 보호법」에 따라 다음과 같이 처리 방침을 공개합니다.

## 제1조 (처리하는 개인정보 항목)

1. 이 앱은 회원가입을 요구하지 않으며, 성명, 주민등록번호, 연락처, 기기 식별값, 위치 정보 등 어떠한 개인정보도 운영자가 수집하지 않습니다.
2. 다음 정보는 이용자가 직접 입력할 때에만 이용자 기기의 브라우저 저장소에 저장되며, 운영자의 서버로 전송되지 않습니다. 운영자는 이 앱을 위한 서버를 운영하지 않습니다.
   - **시험지 자료:** 시험지 이름, 시험 이름·교시 등 머리말, 출제 계획표, 문항(발문, 자료, 선지, 정답, 해설), 지문
   - **성취기준 설정:** 이용자가 추가한 성취기준과 원문 대조 표시
   - **AI 서비스 API 키와 연결 설정(선택):** 키, 고른 AI 서비스와 모델 이름, 요청 간격. ‘이 브라우저에 키 기억하기’를 고른 경우에만 브라우저 저장소에 남고, 고르지 않으면 탭을 닫을 때 지워지는 임시 저장소에 둡니다.
   - **안내 확인 기록:** 사용 전 안내 팝업(출제 주의 사항·개인정보 처리 안내)을 확인했는지 여부와 확인한 안내의 버전. ‘다시 보지 않기’를 고르지 않으면 탭을 닫을 때 지워지는 임시 저장소에만 둡니다.

## 제2조 (개인정보의 처리 목적)

1. 제1조의 정보는 이용자 기기 안에서 출제 작업을 이어 하고, 문항을 PDF·HWP·DOC 파일로 저장하고, AI 서비스 요청을 인증하는 데에만 쓰입니다.
2. 운영자는 이 정보를 열람, 수집, 분석하지 않으며 평가, 광고 등 다른 목적에 이용하지 않습니다.

## 제3조 (보유 및 이용 기간과 파기 절차)

1. 운영자의 서버에 저장하는 정보가 없으므로 운영자가 보유하는 기간은 없습니다.
2. 이용자 기기에 저장된 정보는 이용자가 지울 때까지 남으며, 다음 방법으로 즉시 영구 삭제됩니다: ‘AI 연결’ 화면의 [이 기기의 모든 데이터 지우기] 버튼, [연결 해제·키 지우기] 버튼(API 키), 홈 화면의 시험지 [삭제] 버튼, 브라우저의 사이트 데이터 삭제. 임시 저장소의 API 키는 탭을 닫으면 삭제됩니다.
3. AI 서비스로 보낸 내용의 보관은 제8조에 따릅니다.

## 제4조 (개인정보의 안전성 확보 조치)

1. 시험지 자료와 API 키를 운영자의 서버로 보내지 않고 이용자 기기에만 둡니다.
2. 이 앱은 HTTPS(TLS 암호화)를 제공하는 호스팅(GitHub Pages)을 통해 제공됩니다. 응답 보안 헤더는 호스팅이 정하며, 운영자가 따로 설정하지 않습니다.
3. API 키는 입력할 때 가려서 표시합니다. 앱 코드와 공개 저장소에는 키를 넣지 않습니다.
4. 저장하는 시험지 파일(PDF, HWP, DOC)에는 API 키가 들어가지 않습니다.

## 제5조 (정보주체의 권리·의무 및 행사 방법)

1. 이용자는 언제든지 자기 기기에 저장된 시험지를 앱 화면에서 확인하고, 제3조의 방법으로 즉시 삭제할 수 있습니다.
2. 이용자는 문항 조건, 참고 문항, 지문 등 AI 서비스로 보내는 내용에 학생이나 다른 사람의 개인정보(이름, 학번, 연락처, 성적 등)를 입력하지 않아야 합니다.
3. 개인정보 관련 문의는 제7조의 보호책임자에게 언제든지 요청할 수 있습니다.

## 제6조 (만 14세 미만 아동의 개인정보 처리)

이 앱은 교사용 출제 도구이며, 만 14세 미만 아동을 포함한 모든 이용자의 개인정보를 운영자가 수집하지 않으므로 법정대리인의 별도 동의가 필요한 개인정보 처리가 발생하지 않습니다. 이용자가 AI 서비스의 API 키를 직접 만들어 쓰는 경우에는 그 서비스의 이용 조건(연령 조건 포함)을 따라야 합니다.

## 제7조 (개인정보 보호책임자 및 연락처)

- 운영 기관: 전병제 (개인)
- 개인정보 보호책임자: 전병제 (개인)
- 문의 창구(전자우편): gabriel@gabrielmath.kr

## 제8조 (개인정보의 제3자 제공 및 국외 이전)

1. 운영자는 이용자의 개인정보를 제3자에게 제공하거나 국외로 이전하지 않습니다.
2. 다만 이용자가 AI 기능을 사용하면, 문항을 만들기 위해 다음 내용이 이용자가 입력한 API 키를 발급한 AI 서비스로 전송됩니다. 예: Google(미국)의 Gemini, OpenAI(미국)의 ChatGPT, Anthropic(미국)의 Claude, xAI(미국)의 Grok, Groq(미국), OpenRouter(미국, 이용자가 고른 모델의 제공 회사로 다시 전달), DeepSeek(중국), Mistral(프랑스), Upstage(대한민국), Perplexity(미국), 이용자가 직접 입력한 OpenAI 호환 주소.
   - **전송 항목:** 문항 조건(영역, 과목, 단원, 성취기준, 문항 유형, 행동영역, 난이도, 배점), 이용자가 붙여 넣은 참고 문항 원문과 추가 조건, 지문 세트의 지문, 검토를 요청한 문항의 내용, 지문 작성을 요청한 주제. 브라우저 저장소의 다른 시험지와 설정은 보내지 않습니다.
   - **전송 경로:** 이용자 브라우저에서 해당 AI 서비스의 서버(예: generativelanguage.googleapis.com, api.openai.com, api.anthropic.com)로 직접 전송. 운영자 서버를 거치지 않으며, API 키는 요청 인증과 사용 가능한 모델 목록 확인에만 사용
   - **전송 시점:** 이용자가 [연결하기], [문항 생성 시험], [이 문항 생성], [계획표 전체 생성], [검토위원 재풀이], [AI로 지문 쓰기]를 누를 때
   - **보관 기간:** 해당 AI 서비스의 개인정보 처리방침과 이용 조건에 따름
   - **거부 방법:** AI 기능을 쓰지 않으면 아무것도 전송되지 않으며, 문항 직접 입력·편집·인쇄·저장 기능은 제한 없이 쓸 수 있습니다.

## 제9조 (AI 서비스 API 이용에 관한 사항)

1. **키의 발급과 관리:** API 키는 이용자가 각 AI 서비스에서 개인적으로 만들어 입력합니다. 운영자는 키를 발급하거나 대신 보관하지 않으며, 키의 관리 책임은 이용자에게 있습니다. 공용 컴퓨터에서는 ‘이 브라우저에 키 기억하기’를 끄고, 사용 후 [연결 해제·키 지우기]를 누르세요.
2. **요금:** API 사용 요금은 키를 발급받은 이용자의 계정에 청구됩니다. 운영자는 요금을 받거나 대신 내지 않습니다.
3. **무료 등급의 데이터 이용:** 일부 AI 서비스의 무료 등급(예: Gemini API 무료 사용량)은 이용자가 보낸 내용과 응답을 서비스 개선에 쓰고, 품질 향상을 위해 사람이 검토할 수 있습니다. 공개 전 시험 문항처럼 보안이 필요한 내용은 데이터를 학습에 쓰지 않는 유료 등급을 이용하세요.
4. **서비스 이용 조건 준수:** 이용자는 각 AI 서비스의 이용 약관과 사용 정책(연령, 지역, 금지 용도 포함)을 따라야 합니다.
5. **생성 결과의 검토:** AI가 만든 문항, 정답, 해설은 틀릴 수 있습니다. 시험에 쓰기 전에 교사가 직접 풀어 보고 교육과정 범위와 정답 유일성을 확인해야 합니다.
6. **문항이 만들어지는 방식:** 이 앱은 ‘이 문항 생성’ 또는 ‘계획표 전체 생성’을 누를 때마다 이용자가 고른 조건을 AI 서비스에 보내 새 문항을 만듭니다. 앱 안에는 기출문제나 미리 만들어 둔 문항 은행이 들어 있지 않으며, 저장된 문항을 꺼내 주는 구조가 아닙니다.
7. **기존 문항과의 유사성:** AI는 학습한 자료의 영향을 받기 때문에, 새로 만든 문항이라도 기출문제나 시판 문제집 문항과 비슷하거나 거의 같게 나올 수 있습니다. 이용자는 사용 전 참고한 원문이나 알고 있는 기존 문항과 대조해 지나치게 비슷한 문항은 고치거나 쓰지 않아야 합니다.
8. **저작권:** 수능·모의평가 기출문제의 저작권은 한국교육과정평가원 등 저작권자에게 있습니다. 참고 문항으로 기출문제 등 저작물을 붙여 넣거나 원문에 가까운 문항을 쓸 때에는 출처를 밝히고 저작권자의 이용 조건과 학교의 평가 관리 규정을 따라야 합니다. 이 앱은 원문을 그대로 옮기지 않고 구조만 참고하도록 AI에 요청하지만, AI가 이를 항상 지킨다는 보장은 없습니다.
9. **책임:** 이 앱은 생성 문항의 정확성, 독창성, 저작권 문제가 없음을 보장하지 않으며, 문항 사용에 대한 최종 판단과 책임은 출제 교사에게 있습니다. 자세한 내용은 앱 화면 상단과 하단의 ‘출제 주의 사항’에서 볼 수 있습니다.

## 제10조 (개인정보 처리 업무의 위탁)

운영자는 개인정보 처리 업무를 외부 기관이나 제3자에게 위탁하지 않습니다. AI 요청은 이용자 본인이 입력한 API 키로 처리됩니다.

## 제11조 (자동 수집 장치와 외부 리소스)

1. 이 앱은 쿠키, 방문 분석, 광고 도구를 쓰지 않습니다.
2. 화면 표시와 파일 저장을 위해 다음 외부 리소스를 불러오며, 이때 접속 정보(IP 주소, 브라우저 정보)가 해당 서비스에 전달될 수 있습니다.
   - Google Fonts(fonts.googleapis.com, fonts.gstatic.com): 글꼴
   - jsDelivr(cdn.jsdelivr.net): 수식 표시 도구(MathJax), HWP·DOC 저장 도구(저장 단추를 처음 누를 때)
   - cdnjs(cdnjs.cloudflare.com): PDF 저장 도구

## 제12조 (외부 데이터베이스 및 서버 미사용에 관한 해당 없음 고지)

이 앱은 교육 목적의 정적 웹 애플리케이션으로, 보안 진단 및 점검 항목 중 다음 사항이 [해당 없음]임을 밝힙니다.

1. **외부 데이터베이스(Supabase, PostgreSQL 등)와 RLS 보안 제어: [해당 없음]** 외부 중앙 DB 서버를 구축하거나 운영하지 않으며, 모든 시험지 자료는 이용자의 브라우저 저장소에서만 처리됩니다.
2. **Firebase 데이터베이스와 원격 접근 규칙: [해당 없음]** Firebase(Realtime Database, Firestore)를 사용하지 않습니다.
3. **회원 계정과 세션 쿠키: [해당 없음]** 로그인이나 세션 쿠키를 발행하지 않는 공개형 교육용 앱으로, 인증 기반 API나 쿠키 보안 설정의 대상이 아닙니다.
4. **자체 서버와 전송 프로토콜: [해당 없음]** 운영자가 운영하는 자체 서버가 없으며, 전송 암호화(HTTPS)는 호스팅(GitHub Pages)이 제공합니다.

## 제13조 (개인정보 처리방침의 변경)

1. 이 방침이 바뀌면 앱 화면(사용 전 안내 팝업과 하단 ‘개인정보 처리방침’)과 공개 저장소의 PRIVACY.md에 시행일자와 함께 알립니다.
2. 이 방침은 앱의 실제 동작을 설명한 것이며, 학교에서 도입할 때의 심의는 학교에서 별도로 받아야 합니다.
