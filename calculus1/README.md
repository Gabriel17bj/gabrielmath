# 미적분Ⅰ 개념 탐구 실험실

2022 개정 교육과정 〈미적분Ⅰ〉의 성취기준 20개를 21차시 개념기반 탐구로 엮은 학습용 웹앱입니다. 같은 사이트의 [공통수학 개념 탐구 실험실](../math1/), [대수 개념 탐구 실험실](../algebra/)과 같은 틀(5단계 탐구, 수학 노트, PDF 저장, G-Man 멘토, 개인정보 처리방침)을 쓰고, 내용과 탐색 도구만 〈미적분Ⅰ〉로 바꾸었습니다.

| 단원 | 차시 | 성취기준 |
|---|---|---|
| Ⅰ. 함수의 극한과 연속 | 좌극한과 우극한, 무한대와 발산, 극한의 성질과 0/0 꼴, 미정계수, 연속, 최대·최소 정리와 사잇값 정리 | 12미적Ⅰ-01-01~04 |
| Ⅱ. 미분 ① 미분계수와 도함수 | 평균변화율과 미분계수, 미분가능성과 연속성, 도함수와 xⁿ의 미분, 실수배·합·차·곱의 미분법, 접선의 방정식 | 12미적Ⅰ-02-01~05 |
| Ⅱ. 미분 ② 도함수의 활용 | 평균값 정리, 증가·감소와 극값, 그래프의 개형, 방정식과 부등식, 속도와 가속도 | 12미적Ⅰ-02-06~10 |
| Ⅲ. 적분 ① 부정적분과 정적분 | 부정적분, 넓이로 정의한 정적분과 성질, 넓이 함수와 미적분의 기본정리 | 12미적Ⅰ-03-01~04 |
| Ⅲ. 적분 ② 정적분의 활용 | 곡선으로 둘러싸인 넓이, 속도와 거리 | 12미적Ⅰ-03-05~06 |

## 각 차시의 구성

질문하기(핵심 질문, 배우기 전 예상) → 탐색하기(탐색 도구, 사실적 질문) → 개념화하기(개념적 질문, 나의 일반화, 멘토 피드백, 교사용 일반화, 개념 정리) → 적용과 전이(채점되는 적용 문제 3개, 논쟁적 질문, 전이 과제) → 성찰하기

## 탐색 도구 (21개)

좌극한·우극한 접근 표, x→±∞ 값의 표, 극한의 성질 검증기와 0/0 꼴 확대경, 미정계수 맞추기, 연속의 세 조건 판정기, 최대·최소 정리 반례와 이분법, 할선과 접선(h → 0 애니메이션), 미분가능성 확대 현미경, 기울기 자취로 그리는 도함수, 곱의 미분법 넓이 모형, 접선 탐색기, 평행한 접선 찾기, 증가·감소 색칠 그래프와 자동 증감표, (p, q) 평면에서 보는 삼차함수 분류, f(x)=k 교점 세기, 수직선 위의 운동 애니메이션, 적분상수에 따른 곡선의 모임, 넓이로 보는 정적분, 넓이 함수 S(x), 두 곡선 사이의 넓이, 속도 그래프와 거리

## 교육과정 범위

교육과정의 ‘성취기준 적용 시 고려 사항’에 맞추어 복잡한 합성함수, 몫의 미분법, 이계도함수와 변곡점, 구분구적법, 곡선 운동은 다루지 않습니다. 정적분은 연속이고 음이 아닌 함수의 넓이로 정의한 뒤 일반적인 연속함수로 확장합니다. G-Man 멘토에도 같은 범위를 지키도록 지시되어 있습니다.

## 실행

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 수식 표시 도구(KaTeX, MathJax)가 파일 안에 들어 있어 크기가 약 3MB입니다. G-Man 사용 설명서 그림도 파일 안에 들어 있습니다.

## 저장과 개인정보

- 학습 기록은 `calculus1-inquiry-lab-v1` 이름으로 이 기기의 브라우저에만 저장되며, math1, algebra의 기록과 섞이지 않습니다.
- G-Man 멘토 API 키(`gman-mentor-key-v1`)는 같은 도메인의 math1, algebra와 함께 씁니다. 다만 math1, algebra는 아직 Claude(Anthropic) 키만 쓸 수 있어, 다른 회사 키를 넣으면 그 두 앱에서는 멘토가 작동하지 않습니다.
- 연결 설정(고른 AI 서비스, 모델)은 `gman-mentor-cfg-v2`에 저장됩니다.

## G-Man 멘토와 API 키

- claude.ai 게시 화면에서는 키 없이 작동하고, 그 밖의 곳(gabrielmath.kr, 내 컴퓨터)에서는 API 키가 필요합니다.
- 어느 회사의 키든 붙여 넣으면 키 앞부분으로 회사를 알아내 연결합니다.

| AI 서비스 | 키 모양 | 연결 방식 |
|---|---|---|
| Claude (Anthropic) | `sk-ant-…` | Messages API |
| ChatGPT (OpenAI) | `sk-…`, `sk-proj-…` | Chat Completions |
| Gemini (Google) | `AIza…` | Gemini API |
| OpenRouter, Groq, Grok(xAI), Solar(Upstage), Perplexity | `sk-or-…`, `gsk_…`, `xai-…`, `up_…`, `pplx-…` | OpenAI 호환 |
| DeepSeek, Mistral, 그 밖의 OpenAI 호환 서비스 | 자동 감지 불가 | ‘AI 서비스 직접 고르기’에서 선택(그 밖의 서비스는 주소 직접 입력) |

- 키를 넣으면 그 키로 쓸 수 있는 모델 목록을 불러와 알맞은 모델을 자동으로 고릅니다. 고른 모델이 없어지면 다시 찾아 한 번 더 시도합니다.
- 회사에 따라 웹 브라우저에서 직접 API를 부르는 것(CORS)을 막아 둔 곳이 있습니다. 그런 서비스는 연결 오류가 나며, Claude, ChatGPT, Gemini 키로 바꾸면 됩니다.
- 학생과 교사용 그림 설명서: 앱의 ‘G-Man 사용 설명서’ 화면, 인쇄용은 [G-Man_사용설명서.pdf](./G-Man_사용설명서.pdf)
- 자세한 조항은 [PRIVACY.md](./PRIVACY.md)에 있습니다.

## 내용의 출처

- 교육과정: 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 (미적분Ⅰ)의 성취기준, 성취기준 해설, 핵심 아이디어, 성취기준 적용 시 고려 사항
- 교과서: 아직 연결하지 않았습니다. 앱 화면에는 차시마다 ‘교육과정 성취기준 기반 자체 구성’으로 표시됩니다. 교과서 쪽수를 넣으려면 `index.html`의 차시 데이터에서 `pages:null`을 `pages:'10~16쪽'`처럼 바꾸고, 교과서 상황을 쓴 경우 `SOURCES`에 출처를 적습니다.
- 적용 문제 63개는 모두 성취기준을 바탕으로 새로 만든 자체 제작 문항입니다.
