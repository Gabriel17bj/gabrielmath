# 개인정보 처리방침

**확률과 통계 개념 탐구 실험실 (학생 개인정보 미수집)**

앱 화면 하단의 ‘개인정보 처리방침’을 누르면 같은 내용을 팝업 창으로 볼 수 있습니다.

확률과 통계 개념 탐구 실험실(이하 ‘이 앱’)은 학생의 개인정보를 수집하거나 운영자의 서버에 전송·저장하지 않습니다. 회원가입이나 로그인 없이 바로 쓸 수 있으며, 입력한 내용은 이용자의 기기(브라우저 저장소)에만 보관됩니다. 이 앱은 「개인정보 보호법」에 따라 다음과 같이 처리 방침을 공개합니다.

## 제1조 (처리하는 개인정보 항목)

1. 이 앱은 회원가입을 요구하지 않으며, 성명, 주민등록번호, 연락처, 기기 식별값, 위치 정보 등 어떠한 개인정보도 운영자가 수집하지 않습니다.
2. 다음 정보는 이용자가 직접 입력할 때에만 이용자 기기의 브라우저 저장소에 저장되며, 운영자의 서버로 전송되지 않습니다. 운영자는 이 앱을 위한 서버를 운영하지 않습니다.
   - **이름, 학번(선택):** ‘내 기록 PDF로 저장’ 화면에서 PDF 문서 머리글에 표시하기 위한 용도
   - **학습 기록:** 예상, 관찰 메모, 일반화 문장, 적용 문제 답, 토론 입장, 성찰, 진행 상태, 수학 노트
   - **AI 회사의 API 키(선택):** claude.ai 밖에서 G-Man 멘토를 쓸 때. 기본은 탭을 닫으면 지워지는 임시 저장소에 두고, ‘이 기기에 기억하기’를 고른 경우에만 브라우저 저장소에 저장
   - **G-Man 연결 설정(선택):** 연결된 AI 회사와 모델 이름. 브라우저 저장소에 저장

## 제2조 (개인정보의 처리 목적)

1. 제1조의 정보는 이용자 기기 안에서 학습 활동을 이어 하고, 기록을 PDF로 저장하고, G-Man 멘토 요청을 인증하는 데에만 쓰입니다.
2. 운영자는 이 정보를 열람, 수집, 분석하지 않으며 성적, 평가, 광고에 이용하지 않습니다.
3. 앱 안에서 이루어지는 수식 계산과 그래프 탐색은 교육용 시뮬레이션 목적에만 한정됩니다.

## 제3조 (보유 및 이용 기간과 파기 절차)

1. 운영자의 서버에 저장하는 정보가 없으므로 운영자가 보유하는 기간은 없습니다.
2. 이용자 기기에 저장된 기록은 이용자가 지울 때까지 남으며, 다음 방법으로 즉시 영구 삭제됩니다: 제5조의 [이 기기의 내 기록 모두 지우기] 버튼, 브라우저의 사이트 데이터 삭제, G-Man 멘토 설정의 [키 삭제](API 키). 임시 저장소의 API 키는 탭을 닫으면 삭제됩니다.
3. G-Man 멘토에 보낸 내용의 보관은 제8조에 따릅니다.

## 제4조 (개인정보의 안전성 확보 조치)

1. 학습 기록과 API 키를 운영자의 서버로 보내지 않고 이용자 기기에만 둡니다.
2. 이 앱은 HTTPS(TLS 암호화)를 제공하는 호스팅(claude.ai, GitHub Pages)을 통해 제공됩니다. 응답 보안 헤더는 각 호스팅이 정하며, 운영자가 따로 설정하지 않습니다.
3. API 키는 입력할 때 가려서 표시하고, 저장한 뒤에도 일부만 보여 줍니다. 앱 코드와 공개 저장소에는 키를 넣지 않습니다.
4. 이용자가 입력한 글은 화면에 텍스트로만 표시하며, 프로그램 코드로 실행하지 않습니다.

## 제5조 (정보주체의 권리·의무 및 행사 방법)

1. 이용자는 언제든지 자기 기기에 저장된 기록을 ‘내 기록 PDF로 저장’ 화면에서 확인하고, 앱의 [이 기기의 내 기록 모두 지우기] 버튼이나 브라우저 설정으로 즉시 삭제할 수 있습니다.
2. 이용자는 G-Man 멘토에 자신이나 다른 사람의 개인정보(이름, 학번, 연락처, 주소 등)를 입력하지 않아야 합니다.
3. 개인정보 관련 문의는 제7조의 보호책임자에게 언제든지 요청할 수 있습니다.

## 제6조 (만 14세 미만 아동의 개인정보 처리)

이 앱은 만 14세 미만 학생을 포함한 모든 이용자의 개인정보를 운영자가 수집하지 않으므로, 법정대리인의 별도 동의가 필요한 개인정보 처리가 발생하지 않습니다. 다만 이용자가 AI 회사의 API 키를 직접 만들어 쓰는 경우에는 그 회사의 이용 조건(연령 조건 포함)을 따라야 하며, 학생은 교사나 보호자와 함께 키를 만들도록 안내합니다.

## 제7조 (개인정보 보호책임자 및 연락처)

- 운영 기관: 전병제 (개인)
- 개인정보 보호책임자: 전병제 (개인)
- 문의 창구(전자우편): gabriel@gabrielmath.kr

## 제8조 (개인정보의 제3자 제공 및 국외 이전)

1. 운영자는 이용자의 개인정보를 제3자에게 제공하거나 국외로 이전하지 않습니다.
2. 다만 이용자가 G-Man 멘토를 사용하면, AI 응답을 만들기 위해 다음 내용이 AI 회사로 전송됩니다. claude.ai 게시 화면에서는 Anthropic, PBC(미국)의 Claude로, 그 밖의 곳에서는 이용자가 입력한 API 키를 발급한 회사(Anthropic, OpenAI, Google, OpenRouter, Groq, xAI, DeepSeek, Mistral AI, Perplexity, Upstage 중 해당 회사)의 AI 모델로 전송되며, 이 회사들은 대부분 국외에 있습니다.
   - **전송 항목:** 이용자가 보낸 말, 피드백을 요청한 일반화 문장, 현재 차시 정보와 탐색 도구 상태. 이름, 학번, 그 밖의 학습 기록은 보내지 않습니다.
   - **전송 경로:** claude.ai 게시 화면에서는 claude.ai를 통해, 그 밖의 곳에서는 이용자 브라우저에서 해당 회사의 API 주소(예: api.anthropic.com, api.openai.com, generativelanguage.googleapis.com)로 직접 전송(이때 API 키는 요청 인증에만 사용)
   - **전송 시점:** 이용자가 [보내기] 또는 [G-Man 멘토에게 피드백 받기]를 누를 때
   - **보관 기간:** 해당 AI 회사(와 claude.ai)의 개인정보 처리방침과 이용 조건에 따름
   - **거부 방법:** G-Man 멘토를 쓰지 않으면 아무것도 전송되지 않으며, 그 밖의 학습 기능 이용에는 제한이 없습니다.

## 제9조 (개인정보 처리 업무의 위탁)

운영자는 개인정보 처리 업무를 외부 기관이나 제3자에게 위탁하지 않습니다. G-Man 멘토 요청은 이용자가 이용하는 claude.ai 또는 이용자 본인이 입력한 API 키로 처리됩니다.

## 제10조 (자동 수집 장치와 외부 리소스)

1. 이 앱은 쿠키, 방문 분석, 광고 도구를 쓰지 않습니다.
2. 화면 표시를 위해 다음 외부 리소스를 불러오며, 이때 접속 정보(IP 주소, 브라우저 정보)가 해당 서비스에 전달될 수 있습니다.
   - Google Fonts(fonts.googleapis.com, fonts.gstatic.com): 글꼴
   - jsDelivr(cdn.jsdelivr.net): PDF 저장 도구(‘PDF 파일로 저장’을 처음 누를 때)
   - 수식 표시 도구는 앱 안에 들어 있어 외부로 요청하지 않습니다.

## 제11조 (외부 데이터베이스 및 서버 미사용에 관한 해당 없음 고지)

이 앱은 교육 목적의 정적 웹 애플리케이션으로, 보안 진단 및 점검 항목 중 다음 사항이 [해당 없음]임을 밝힙니다.

1. **외부 데이터베이스(Supabase, PostgreSQL 등)와 RLS 보안 제어: [해당 없음]** 외부 중앙 DB 서버를 구축하거나 운영하지 않으며, 모든 학습 데이터는 이용자의 브라우저 저장소에서만 처리됩니다.
2. **Firebase 데이터베이스와 원격 접근 규칙: [해당 없음]** Firebase(Realtime Database, Firestore)를 사용하지 않습니다.
3. **회원 계정과 세션 쿠키: [해당 없음]** 로그인이나 세션 쿠키를 발행하지 않는 공개형 교육용 앱으로, 인증 기반 API나 쿠키 보안 설정의 대상이 아닙니다.
4. **자체 서버와 전송 프로토콜: [해당 없음]** 운영자가 운영하는 자체 서버가 없으며, 전송 암호화(HTTPS)는 호스팅(claude.ai, GitHub Pages)이 제공합니다.

## 제12조 (개인정보 처리방침의 변경)

1. 이 방침이 바뀌면 앱 화면과 공개 저장소의 PRIVACY.md에 시행일자와 함께 알립니다.
2. 이 방침은 앱의 실제 동작을 설명한 것이며, 학교에서 도입할 때의 심의는 학교에서 별도로 받아야 합니다.
