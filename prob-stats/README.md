# 확률과 통계 개념 탐구 실험실

2022 개정 교육과정 〈확률과 통계〉(일반 선택)의 성취기준 16개를 20차시 개념기반 탐구로 엮은 학습용 웹앱입니다. 같은 사이트의 [공통수학](../math1/), [대수](../algebra/), [미적분Ⅰ](../calculus1/), [미적분Ⅱ](../calculus2/) 개념 탐구 실험실과 같은 틀(5단계 탐구, 수학 노트, PDF 저장, G-Man 멘토, 개인정보 처리방침)을 쓰고, 내용과 탐색 도구만 〈확률과 통계〉로 바꾸었습니다. 확률과 통계의 특성에 맞추어 16개 차시에 **반복 실험**(1번, 10번, 100번, 1000번, 계속 실험하기)을 넣었습니다.

주소: [gabrielmath.kr/prob-stats](https://gabrielmath.kr/prob-stats/)

| 단원 (동아출판 〈확률과 통계〉) | 차시 | 쪽수 | 성취기준 |
|---|---|---|---|
| Ⅰ. 경우의 수 | 중복순열, 같은 것이 있는 순열, 중복조합, 이항정리 | 10~29쪽 | 12확통01-01~03 |
| Ⅱ. 확률 | 수학적 확률과 통계적 확률, 덧셈정리, 여사건, 조건부확률, 곱셈정리, 독립과 종속, 독립시행 | 38~65쪽 | 12확통02-01~06 |
| Ⅲ. 확률분포 | 확률변수와 확률분포, 기댓값과 표준편차, 이항분포와 큰 수의 법칙, 정규분포와 표준화, 이항분포와 정규분포의 관계 | 74~106쪽 | 12확통03-01~04 |
| Ⅳ. 통계적 추정 | 모집단과 표본, 모평균과 표본평균, 모평균의 추정, 모비율의 추정 | 114~137쪽 | 12확통03-05~07 |

## 각 차시의 구성

질문하기(핵심 질문, 배우기 전 예상) → 탐색하기(탐색 도구와 실험, 사실적 질문) → 개념화하기(개념적 질문, 나의 일반화, 멘토 피드백, 교사용 일반화, 개념 정리) → 적용과 전이(채점되는 적용 문제 3개, 전이 과제, 논쟁적 질문) → 성찰하기

## 탐색 도구와 실험 (20개 차시)

- **경우의 수:** 자리별 경우의 수 카드와 🎲 무작위로 비밀 코드 맞히기, 번호를 붙였다 떼는 공 배열과 최단 경로(모든 경로 겹치기, 점마다 경로 수), 메뉴 주문의 별·막대 표현과 $x+y+z=r$ 의 삼각 격자, 전개식 낱말 세기와 눌러 보는 파스칼의 삼각형, 일반항 계산기
- **확률:** 🎲 동전·주사위·버터 토스트 상대도수 실험(세 번 겹쳐 보기, 로그 눈금), 두 주사위 표본공간(사건을 직접 만들기), 🎲 배수 색칠판과 벤 다이어그램, 🎲 생일 달력 실험, ‘적어도 한 번’ 막대그래프, 1000명 바이러스 검사 점 그림, 조건으로 줄어드는 표본공간, 🎲 제비뽑기 순서 공정성 실험, 나무그림, 넓이 모형으로 보는 독립, 🎲 복원·비복원 추출 실험, 🎲 독립시행
- **확률분포:** 🎲 두 주사위 확률변수(합, 차, 큰 수, 점수 게임), 🎲 연속확률변수의 넓이와 히스토그램, 확률분포 시소(균형점과 표준편차), $aX+b$ 변환, 🎲 주사위 게임 기댓값 실험, 🎲 이항분포, 큰 수의 법칙, 정규분포 곡선, 표준화 두 그래프와 표준정규분포표, 🎲 키 히스토그램이 곡선이 되는 실험, 이항분포와 정규분포 겹쳐 보기, 🎲 갈톤 보드, 정규근사 계산기
- **통계적 추정:** 🎲 가상 학교 400명에서 임의추출·편의추출·자발적 응답 비교, 공 1·2·3·4 표본 전체 나열, 🎲 모집단 모양별 표본평균 분포, 🎲 신뢰구간 100개 만들기, 신뢰구간 해석 고르기, 🎲 표본비율 분포, 🎲 두 후보 여론조사와 오차 범위

## 교육과정 범위

교육과정의 ‘성취기준 해설’과 ‘성취기준 적용 시 고려 사항’에 맞추었습니다. 항이 세 개 이상인 다항정리와 허수단위가 있는 이항정리, 세 사건 이상이 배반이거나 독립인 복잡한 문제는 넣지 않았습니다. 조건부확률을 시간 순서나 인과관계로 해석하지 않도록 개념 정리와 논쟁적 질문에서 짚었습니다. 이항분포의 평균·분산 공식은 증명하지 않고 실험으로 확인하며, 모평균 추정은 모집단이 정규분포인 경우, 모비율 추정은 표본이 큰 경우만 다룹니다. 복잡한 신뢰구간 계산은 넣지 않았습니다. G-Man 멘토에도 같은 범위를 지키도록 지시되어 있습니다.

## 실행

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 수식 표시 도구(KaTeX, MathJax)가 파일 안에 들어 있어 크기가 약 2.7MB입니다. 실험의 난수는 브라우저 안에서 만들며, 결과는 매번 달라집니다.

## 저장과 개인정보

- 학습 기록은 `prob-stats-inquiry-lab-v1` 이름으로 이 기기의 브라우저에만 저장되며, math1, algebra, calculus1, calculus2의 기록과 섞이지 않습니다.
- G-Man 멘토 API 키 설정(`gman-mentor-key-v1`)은 같은 도메인의 다른 웹앱과 함께 씁니다. 한 번 넣으면 모든 앱에서 작동합니다.
- 자세한 조항은 [PRIVACY.md](./PRIVACY.md)에 있습니다.

## 내용의 출처

- 교육과정: 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 (확률과 통계)의 성격, 목표, 핵심 아이디어, 성취기준, 성취기준 해설, 성취기준 적용 시 고려 사항, 교수·학습 방법
- 교과서: 동아출판 〈확률과 통계〉 교과서의 단원 구성과 쪽수, 일부 탐색 상황(자동 등록 방지 코드, 구슬 장치, 버터 토스트, 생일 문제, 진단 검사, 추첨 순서, 거짓말 탐지기, 주사위 점수 게임, 학생 키 히스토그램, 안경 착용 비율, 공 1·2·3·4, 출구조사, 오차 범위 내 접전). 차시마다 ‘질문하기’와 ‘적용과 전이’ 단계에 출처를 표시했습니다. 수치와 자료는 대부분 새로 정했습니다.
- 적용 문제 60개는 모두 성취기준을 바탕으로 새로 만든 자체 제작 문항입니다.
