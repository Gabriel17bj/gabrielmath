🔑 API 키가 뭐예요?

API 키는 AI 회사의 서비스를 쓸 수 있게 해 주는 비밀번호 같은 긴 글자예요. 이 실험실은 서버가 없어서, G-Man이 대답하려면 내가 가진 키로 AI 회사에 직접 물어봐야 해요.

  • 어느 회사 키든 돼요. 아래 표의 회사 중 어디에서 받은 키든 붙여 넣으면, G-Man이 어느 회사 키인지 알아내고 알맞은 모델을 골라요.
  • claude.ai에서 열면 키가 필요 없어요. gabrielmath.kr에서 열 때만 키가 필요해요.
  • 요금은 키 주인에게 청구돼요. 무료로 쓸 수 있는 양이 있는 곳도 있지만, 넘으면 요금이 나올 수 있어요. 키를 만들 때 사용 한도를 낮게 정해 두면 안심이에요.
  • 나이 조건을 확인해요. 회사마다 가입할 수 있는 나이가 정해져 있어요. 학생이 직접 만들기 어렵다면 선생님이나 보호자와 함께 준비해요.

💬 G-Man과 잘 이야기하는 법

👍 이렇게 말해요
  • “r = 0.9로 바꿨더니 점이 0에 가까워졌어요. 왜 그럴까요?”처럼 탐색 도구에서 본 것을 함께 적어요.
  • “나는 이렇게 생각했는데 맞을까?”처럼 내 생각을 먼저 말해요.
  • 수식은 $x^{2}$처럼 달러 기호로 감싸 써요.
✋ 이렇게는 말하지 않아요
  • “답만 알려 줘.” G-Man은 정답 대신 생각할 질문을 줘요.
  • 이름, 학번, 전화번호, 주소 같은 개인정보
  • API 키 자체를 대화창에 적기

AI도 틀릴 수 있어요. 이상하다 싶으면 교과서를 보거나 선생님께 여쭤봐요.

🔒 꼭 지켜요

  • API 키는 비밀번호예요. 친구에게 보여 주거나 메신저, 과제, 화면 공유에 올리지 않아요.
  • 학교 컴퓨터에서는 ‘이 기기에 기억하기’를 켜지 않고, 다 쓰면 ‘키 삭제’를 눌러요.
  • 선생님의 키를 학생 기기에 기억해 두지 않아요.
  • 키가 남에게 알려진 것 같으면 그 키를 만든 누리집에서 바로 삭제하고 새로 만들어요.
  • 키는 이 기기에서 그 AI 회사로만 보내지고, 선생님이나 앱 운영자에게는 보내지 않아요. 자세한 내용은 개인정보 처리방침에 있어요.
