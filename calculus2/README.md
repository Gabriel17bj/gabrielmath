# 미적분Ⅱ 개념 탐구 실험실

2022 개정 교육과정 〈미적분Ⅱ〉(진로 선택)의 성취기준 23개를 27차시 개념기반 탐구로 엮은 학습용 웹앱입니다. 같은 사이트의 [공통수학](../math1/), [대수](../algebra/), [미적분Ⅰ](../calculus1/) 개념 탐구 실험실과 같은 틀(5단계 탐구, 수학 노트, PDF 저장, G-Man 멘토, 개인정보 처리방침)을 쓰고, 내용과 탐색 도구만 〈미적분Ⅱ〉로 바꾸었습니다.

주소: [gabrielmath.kr/calculus2](https://gabrielmath.kr/calculus2/)

| 단원 | 차시 | 성취기준 |
|---|---|---|
| Ⅰ. 수열의 극한 | 수렴과 발산, 극한의 성질(∞/∞, ∞−∞, 대소 관계), 등비수열의 극한, 급수의 수렴과 발산, 등비급수의 합, 등비급수의 활용 | 12미적Ⅱ-01-01~05 |
| Ⅱ. 미분법 ① 여러 가지 함수의 미분 | e와 지수·로그함수의 극한, 지수·로그함수의 미분, 덧셈정리, 삼각함수의 극한, sin·cos의 미분 | 12미적Ⅱ-02-01~03 |
| Ⅱ. 미분법 ② 여러 가지 미분법 | 몫의 미분법, 합성함수의 미분법, 매개변수의 미분법, 음함수·역함수의 미분법, 다양한 곡선의 접선 | 12미적Ⅱ-02-04~08 |
| Ⅱ. 미분법 ③ 도함수의 활용 | 이계도함수와 변곡점, 그래프의 개형, 방정식과 부등식, 속도와 가속도 | 12미적Ⅱ-02-09~11 |
| Ⅲ. 적분법 ① 여러 가지 적분법 | 여러 가지 함수의 부정적분과 정적분, 치환적분법, 부분적분법 | 12미적Ⅱ-03-01~03 |
| Ⅲ. 적분법 ② 정적분의 활용 | 정적분과 급수의 합, 곡선으로 둘러싸인 넓이, 입체도형의 부피, 속도와 거리 | 12미적Ⅱ-03-04~07 |

## 각 차시의 구성

질문하기(핵심 질문, 배우기 전 예상) → 탐색하기(탐색 도구, 사실적 질문) → 개념화하기(개념적 질문, 나의 일반화, 멘토 피드백, 교사용 일반화, 개념 정리) → 적용과 전이(채점되는 적용 문제 3개, 논쟁적 질문, 전이 과제) → 성찰하기

## 탐색 도구 (27개)

수열의 점 그래프와 극한값 후보의 띠, ∞/∞·∞−∞·대소 관계 탐색, 공비에 따른 rⁿ과 수렴 지도, 항과 부분합 그래프(조화급수 포함), 등비급수의 부분합과 수직선 위의 뜀뛰기, 튀는 공과 중점을 이은 정사각형, (1+1/n)ⁿ과 복리·밑에 따른 기울기, 지수·로그함수 기울기의 자취, 단위원 회전으로 보는 덧셈정리와 두 직선이 이루는 각, 부채꼴과 삼각형의 넓이 비교, sin·cos 기울기의 자취와 덧셈정리로 분해한 평균변화율, 몫의 미분법과 잘못된 추측 비교, x→u→y 세 수직선의 변화 배율, 매개변수 곡선(타원, 사이클로이드, 뾰족점)의 변화율과 접선, 음함수 곡선의 접선과 역함수의 대칭 접선, 접선의 방정식과 곡선 밖의 점에서 그은 접선, 볼록한 방향 색칠과 굴러가는 접선, f′·f″·극한을 차례로 켜는 개형 그리기와 자동 증감표, 수평선으로 교점 세기와 eˣ ≥ ax, 단진동·감쇠 진동의 속도와 가속도, 1/x 아래 넓이와 ln x·r→−1의 극한, 치환적분의 넓이 보존, 부분적분의 직사각형 그림, 직사각형 넓이의 합과 급수를 정적분으로 읽기, 가로 띠·세로 띠 넓이 비교, 단면을 쌓은 입체와 기울어진 동전 더미, 속도 그래프의 부호 있는 넓이와 이동

## 교육과정 범위

교육과정의 ‘성취기준 해설’과 ‘성취기준 적용 시 고려 사항’에 맞추어, 지수·로그·삼각함수의 극한은 도함수를 구하는 데 필요한 정도로, 매개변수와 음함수는 간단한 것만, 이계도함수는 볼록과 변곡점의 기하적 의미로 다룹니다. 급수의 일반항이 등차수열과 등비수열의 곱인 경우처럼 지나치게 복잡한 문제는 넣지 않았습니다. 속도·가속도와 거리는 수직선 위의 운동으로 한정했으며, 교육과정에 명시되지 않은 평면 위의 운동과 곡선의 길이는 넣지 않았습니다. G-Man 멘토에도 같은 범위를 지키도록 지시되어 있습니다.

## 실행

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 수식 표시 도구(KaTeX, MathJax)가 파일 안에 들어 있어 크기가 약 2.7MB입니다.

## 저장과 개인정보

- 학습 기록은 `calculus2-inquiry-lab-v1` 이름으로 이 기기의 브라우저에만 저장되며, math1, algebra, calculus1의 기록과 섞이지 않습니다.
- G-Man 멘토 API 키 설정(`gman-mentor-key-v1`)은 같은 도메인의 다른 웹앱과 함께 씁니다. 한 번 넣으면 모든 앱에서 작동합니다.
- 자세한 조항은 [PRIVACY.md](./PRIVACY.md)에 있습니다.

## 내용의 출처

- 교육과정: 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 (미적분Ⅱ)의 성격, 목표, 핵심 아이디어, 성취기준, 성취기준 해설, 성취기준 적용 시 고려 사항, 교수·학습 방법
- 교과서: 아직 연결하지 않았습니다. 앱 화면에는 차시마다 ‘교육과정 성취기준 기반 자체 구성’으로 표시됩니다. 교과서 쪽수를 넣으려면 `index.html`의 차시 데이터에서 `pages:null`을 `pages:'10~16쪽'`처럼 바꾸고, 교과서 상황을 쓴 경우 `SOURCES`에 출처를 적습니다.
- 적용 문제 81개는 모두 성취기준을 바탕으로 새로 만든 자체 제작 문항입니다.
