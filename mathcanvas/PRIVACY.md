# 개인정보 처리방침

**Math Canvas (학생 개인정보 미수집)**

앱 화면 아래쪽의 ‘개인정보 처리방침’을 누르면 같은 내용을 볼 수 있습니다.

Math Canvas(gabrielmath.kr/mathcanvas, 이하 ‘이 앱’)는 수식, 그래프, 도형, 입체도형 이미지를 만드는 교육용 웹앱입니다. 이 앱은 이용자의 개인정보를 수집하거나 운영자의 서버에 전송·저장하지 않습니다. 회원가입이나 로그인 없이 바로 쓸 수 있으며, 만든 그림과 설정은 이용자의 기기(브라우저 저장소)에만 보관됩니다. 이 앱은 「개인정보 보호법」에 따라 다음과 같이 처리 방침을 공개합니다.

## 제1조 (처리하는 개인정보 항목)

1. 이 앱은 회원가입을 요구하지 않으며, 성명, 주민등록번호, 연락처, 기기 식별값, 위치 정보 등 어떠한 개인정보도 운영자가 수집하지 않습니다.
2. 다음 정보는 이용자가 이 앱을 쓸 때 이용자 기기의 브라우저 저장소에만 저장되며, 운영자의 서버로 전송되지 않습니다. 운영자는 이 앱을 위한 서버를 운영하지 않습니다.
   - **작업 내용과 화면 설정:** 수식, 그래프의 식과 설정, 평면도형, 입체도형과 3D 곡면 설정, 내 작업실(이용자가 넣은 그림 파일 포함), 배경·해상도 선택 (`mathcanvas:v1:` 로 시작하는 이름)
   - **AI 수학 삽화 설정:** 고른 AI 회사, 모델 이름, 스타일, 마지막으로 쓴 설명 문장
   - **AI API 키(선택):** AI 수학 삽화를 쓸 때 이용자가 직접 발급받아 넣은 키. 기본적으로 탭을 닫으면 지워지는 임시 저장소(sessionStorage)에 두고, ‘이 브라우저에 키 기억하기’를 고른 경우에만 브라우저 저장소(localStorage)에 저장합니다. 키 칸(`gman-mentor-key-v1`)은 같은 도메인의 다른 Gabriel Math 웹앱(G-Man 멘토)과 함께 씁니다.
3. AI 수학 삽화로 만든 그림은 이용자가 저장하거나 내 작업실로 보내기 전까지 열려 있는 화면에만 있으며, 페이지를 닫으면 사라집니다.

## 제2조 (개인정보의 처리 목적)

1. 제1조의 정보는 이용자 기기 안에서 작업을 이어 하고, AI 수학 삽화 요청을 인증하는 데에만 쓰입니다.
2. 운영자는 이 정보를 열람, 수집, 분석하지 않으며 성적, 평가, 광고에 이용하지 않습니다.

## 제3조 (보유 및 이용 기간과 파기 절차)

1. 운영자의 서버에 저장하는 정보가 없으므로 운영자가 보유하는 기간은 없습니다.
2. 이용자 기기에 저장된 정보는 이용자가 지울 때까지 남으며, 다음 방법으로 즉시 영구 삭제됩니다: 이 처리방침 화면의 [저장된 API 키 지우기]와 [이 브라우저의 Math Canvas 데이터 모두 지우기] 버튼, AI 수학 삽화 화면의 [저장된 키 지우기] 버튼, 브라우저의 사이트 데이터 삭제. 임시 저장소의 API 키는 탭을 닫으면 삭제됩니다.
3. AI 회사로 보낸 내용의 보관은 제8조에 따릅니다.

## 제4조 (개인정보의 안전성 확보 조치)

1. 작업 내용과 API 키를 운영자의 서버로 보내지 않고 이용자 기기에만 둡니다.
2. 이 앱은 HTTPS(TLS 암호화)를 제공하는 호스팅(GitHub Pages)을 통해 제공됩니다. 응답 보안 헤더는 호스팅이 정하며, 운영자가 따로 설정하지 않습니다.
3. API 키는 입력할 때 가려서 표시합니다. 앱 코드와 공개 저장소에는 키를 넣지 않습니다.
4. AI가 돌려준 SVG 그림은 화면에 넣기 전에 스크립트, 외부 연결, 이벤트 속성을 지우고 이미지로만 표시하여, 그림 안의 코드가 실행되지 않게 합니다.

## 제5조 (정보주체의 권리·의무 및 행사 방법)

1. 이용자는 언제든지 자기 기기에 저장된 정보를 제3조의 버튼이나 브라우저 설정으로 즉시 삭제할 수 있습니다.
2. 이용자는 AI 수학 삽화의 설명 문장에 자신이나 다른 사람의 개인정보(이름, 학번, 연락처, 주소, 성적 등)를 입력하지 않아야 합니다.
3. 이용자는 자신의 API 키를 다른 사람에게 알려 주거나 학습지, 게시판, 공개 저장소에 올리지 않아야 합니다.
4. 개인정보 관련 문의는 제7조의 보호책임자에게 언제든지 요청할 수 있습니다.

## 제6조 (만 14세 미만 아동의 개인정보 처리)

이 앱은 만 14세 미만 학생을 포함한 모든 이용자의 개인정보를 운영자가 수집하지 않으므로, 법정대리인의 별도 동의가 필요한 개인정보 처리가 발생하지 않습니다. 다만 이용자가 AI 회사의 API 키를 직접 발급받아 쓰는 경우에는 그 회사의 이용 조건(연령 조건 포함)을 따라야 하며, 학생은 교사나 보호자의 안내 아래 사용할 것을 권장합니다.

## 제7조 (개인정보 보호책임자 및 연락처)

- 운영 기관: 전병제 (개인)
- 개인정보 보호책임자: 전병제 (개인)
- 문의 창구(전자우편): gabriel@gabrielmath.kr

개인정보 침해에 대한 상담이나 신고는 다음 기관에도 할 수 있습니다: 개인정보침해신고센터(privacy.kisa.or.kr, 국번 없이 118), 개인정보분쟁조정위원회(www.kopico.go.kr, 1833-6972), 대검찰청(www.spo.go.kr, 국번 없이 1301), 경찰청(ecrm.police.go.kr, 국번 없이 182).

## 제8조 (개인정보의 제3자 제공 및 국외 이전)

1. 운영자는 이용자의 개인정보를 제3자에게 제공하거나 국외로 이전하지 않습니다.
2. 다만 이용자가 AI 수학 삽화를 사용하면, 다음 내용이 이용자가 입력한 API 키를 발급한 AI 회사(예: OpenAI, Anthropic, Google, OpenRouter, xAI, Groq, DeepSeek. 대부분 미국 등 국외 소재)로 전송됩니다.
   - **전송 항목:** [연결 확인]을 누를 때는 API 키만, [삽화 만들기]를 누를 때는 API 키, 이용자가 쓴 설명 문장, 고른 스타일에 따른 그리기 지시, 모델 이름. 작업 내용과 그 밖의 정보는 보내지 않습니다.
   - **전송 경로:** 운영자 서버를 거치지 않고 이용자 브라우저에서 키를 발급한 회사의 API 주소(예: api.openai.com, api.anthropic.com, generativelanguage.googleapis.com, openrouter.ai, api.x.ai, api.groq.com, api.deepseek.com) 또는 이용자가 직접 입력한 OpenAI 호환 주소로 직접 전송(이때 API 키는 요청 인증에만 사용). 회사를 자동으로 찾을 때 키 모양만으로 회사를 알 수 없으면 여러 회사에 차례로 연결을 시도할 수 있습니다.
   - **전송 시점:** 이용자가 [연결 확인] 또는 [삽화 만들기]를 누를 때
   - **보관 기간:** 전송받은 AI 회사의 개인정보 처리방침과 이용 조건에 따름
   - **거부 방법:** AI 수학 삽화를 쓰지 않으면 아무것도 전송되지 않으며, 수식·그래프·도형·입체·내 작업실·템플릿 기능 이용에는 제한이 없습니다.

## 제9조 (개인정보 처리 업무의 위탁)

운영자는 개인정보 처리 업무를 외부 기관이나 제3자에게 위탁하지 않습니다. AI 수학 삽화 요청은 이용자 본인이 입력한 API 키를 발급한 AI 회사에서 처리됩니다.

## 제10조 (자동 수집 장치와 외부 리소스)

1. 이 앱은 쿠키, 방문 분석, 광고 도구를 쓰지 않습니다.
2. 화면 표시와 계산을 위해 다음 외부 리소스를 불러오며, 이때 접속 정보(IP 주소, 브라우저 정보)가 해당 서비스에 전달될 수 있습니다.
   - Google Fonts(fonts.googleapis.com, fonts.gstatic.com): 글꼴(Poppins, Nanum Pen Script)
   - jsDelivr(cdn.jsdelivr.net): 글꼴(Pretendard), 수식 표시 도구(MathJax), 3D 보조 도구(three.js 예제 코드)
   - cdnjs(cdnjs.cloudflare.com): 계산 도구(math.js), 3D 도구(three.js)

## 제11조 (외부 데이터베이스 및 서버 미사용에 관한 해당 없음 고지)

이 앱은 교육 목적의 정적 웹 애플리케이션으로, 보안 진단 및 점검 항목 중 다음 사항이 [해당 없음]임을 밝힙니다.

1. **외부 데이터베이스(Supabase, PostgreSQL 등)와 RLS 보안 제어: [해당 없음]** 외부 중앙 DB 서버를 구축하거나 운영하지 않으며, 모든 작업 데이터는 이용자의 브라우저 저장소에서만 처리됩니다.
2. **Firebase 데이터베이스와 원격 접근 규칙: [해당 없음]** Firebase(Realtime Database, Firestore)를 사용하지 않습니다.
3. **회원 계정과 세션 쿠키: [해당 없음]** 로그인이나 세션 쿠키를 발행하지 않는 공개형 교육용 앱으로, 인증 기반 API나 쿠키 보안 설정의 대상이 아닙니다.
4. **자체 서버와 전송 프로토콜: [해당 없음]** 운영자가 운영하는 자체 서버가 없으며, 전송 암호화(HTTPS)는 호스팅(GitHub Pages)이 제공합니다.

## 제12조 (개인 API 키의 발급과 관리)

1. **발급:** AI 수학 삽화를 쓰려는 이용자는 AI 회사(예: Google AI Studio, OpenAI Platform, Claude Console, OpenRouter)에 직접 가입하여 개인 API 키를 발급받습니다. 이때 이용자가 그 회사에 제공하는 이메일, 결제 정보 등은 이용자와 해당 회사 사이에서 처리되며 운영자에게 전달되지 않습니다. 발급 순서는 앱의 ‘API 키 안내’ 화면에 있습니다.
2. **사용 범위:** API 키는 AI 수학 삽화 화면에서만 쓰입니다. 그 밖의 기능은 API 키를 쓰지 않으며 어떤 정보도 외부로 보내지 않습니다.
3. **요금:** AI 회사의 이용 요금은 키를 발급받은 이용자의 계정에 청구되며, 운영자는 요금을 받거나 대신 내지 않습니다. AI 회사 관리 화면에서 사용 한도를 정해 둘 것을 권장합니다.
4. **유출 시 조치:** 키가 다른 사람에게 알려졌다고 생각되면 해당 회사의 관리 화면에서 키를 즉시 삭제하고 새로 발급해야 합니다. 운영자는 이용자의 키를 보관하지 않으므로 대신 폐기할 수 없습니다.
5. **공용 기기:** 학교 컴퓨터실 등 여러 사람이 쓰는 기기에서는 ‘이 브라우저에 키 기억하기’를 켜지 말고, 사용을 마치면 [저장된 키 지우기]를 누릅니다.

## 제13조 (개인정보 처리방침의 변경)

1. 이 방침이 바뀌면 앱 화면과 공개 저장소의 PRIVACY.md에 시행일자와 함께 알립니다.
2. 이 방침은 앱의 실제 동작을 설명한 것이며, 학교에서 도입할 때의 심의는 학교에서 별도로 받아야 합니다.
