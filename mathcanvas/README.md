# Math Canvas

**수학을 그리다, 생각을 펼치다.** 수업용 수식, 함수 그래프, 기하 도형, 입체도형 이미지를 만드는 Gabriel Math의 수학 이미지 제작 도구입니다. 교사는 수업 자료·문제 삽화·인포그래픽을, 학생은 수학 개념을 나만의 그림으로 만들 수 있습니다.

주소: [gabrielmath.kr/mathcanvas](https://gabrielmath.kr/mathcanvas/)

## 기능

| 화면 | 주소 | 내용 | API 키 |
|---|---|---|---|
| 캔버스 홈 | `#home` | 만들기 카드 5개, 템플릿·내 작업실 바로가기 | 필요 없음 |
| 수식 이미지 | `#formula` | LaTeX 입력, 빠른 입력 버튼 64개, 예시 수식 16개 | 필요 없음 |
| 함수 그래프 | `#graph` | 함수, 음함수, 부등식의 영역, 점, 정적분 넓이 색칠, π/2 눈금, 이름표 자동 배치 | 필요 없음 |
| 기하 도형 | `#geometry` | 점·선분·직선·원·다각형·각·글자 도구, 직각·같은 길이·같은 각 표시, 도형 바로 만들기 10종 | 필요 없음 |
| 입체 도형 | `#solid` | 입체도형 14종(가려진 모서리 자동 점선), 3D 곡면 z = f(x, y) | 필요 없음 |
| 내 작업실 | `#board` | 만든 그림을 한 장에 모으고 글자·화살표·펜·그림 파일 추가 | 필요 없음 |
| 템플릿 | `#templates` | 수식 4, 그래프 5, 도형 4, 입체 4개 | 필요 없음 |
| AI 수학 삽화 | `#ai` | 개인 API 키로 정확한 도형(SVG) 또는 그림(이미지) 생성 | **필요** |
| API 키 안내 | `#apikey` | 키가 쓰이는 곳, 회사별 발급 순서, 안전 수칙 | - |
| 개인정보 처리방침 | `#privacy` | [PRIVACY.md](./PRIVACY.md)와 같은 내용, 저장 데이터 지우기 버튼 | - |

모든 그림은 PNG(1~4배, 흰색·투명 배경), SVG로 저장하거나 이미지 복사로 한글·PPT에 붙여 넣을 수 있습니다(입체 도형은 PNG만). 이미지 복사는 HTTPS 주소에서만 작동합니다.

## AI 수학 삽화와 API 키

- 키 앞부분으로 회사를 자동으로 찾습니다: `sk-ant-` Claude, `AIza` Gemini, `sk-or-` OpenRouter, `xai-` xAI, `gsk_` Groq, `sk-` OpenAI(또는 DeepSeek). 그 밖의 서비스는 ‘OpenAI 호환 서비스’에 API 주소를 넣어 씁니다.
- 정확한 도형(SVG)은 모든 회사에서, 그림(이미지)은 OpenAI, Gemini, xAI에서 됩니다.
- 키 칸 `gman-mentor-key-v1`은 같은 도메인의 다른 Gabriel Math 웹앱(G-Man 멘토)과 함께 씁니다. 기본은 탭을 닫으면 지워지는 sessionStorage, ‘이 브라우저에 키 기억하기’를 고르면 localStorage에 저장합니다.
- 키와 요청은 운영자 서버를 거치지 않고 브라우저에서 AI 회사로 바로 전송됩니다. 요금은 키 주인의 계정에 청구됩니다.
- AI 회사들이 모델 이름을 바꾸면 ‘서비스와 모델 직접 고르기’에서 모델 이름을 바꿔 쓰면 됩니다. 기본 모델 이름은 `index.html`의 `PROV` 목록에 있습니다.

## 실행

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 로고와 캐릭터 그림은 파일 안에 이미지 데이터로 들어 있어 따로 올릴 이미지 파일이 없습니다. 실행 중에 MathJax, math.js, three.js와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다. 자세한 목록은 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)에 있습니다.

## 저장과 개인정보

- 작업 내용과 설정은 `mathcanvas:v1:` 로 시작하는 이름으로 이 기기의 브라우저에만 저장되며, 다른 웹앱의 기록과 섞이지 않습니다.
- 회원가입·로그인·쿠키·방문 분석이 없고, 운영자는 서버를 운영하지 않습니다.
- 자세한 조항은 [PRIVACY.md](./PRIVACY.md)에 있습니다.
