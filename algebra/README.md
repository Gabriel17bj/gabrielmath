# 대수 개념 탐구 실험실

2022 개정 교육과정 〈대수〉의 성취기준 18개를 21차시 개념기반 탐구로 엮은 학습용 웹앱입니다. 같은 사이트의 [공통수학 개념 탐구 실험실](../math1/)과 같은 틀(5단계 탐구, 수학 노트, PDF 저장, G-Man 멘토, 개인정보 처리방침)을 쓰고, 내용과 탐색 도구만 〈대수〉로 바꾸었습니다.

| 단원 (동아출판 〈대수〉) | 차시 | 성취기준 |
|---|---|---|
| Ⅰ. 지수와 로그 | 거듭제곱근, 지수의 확장, 지수법칙, 로그의 뜻과 성질, 계산자, 상용로그 | 12대수01-01~05 |
| Ⅱ. 지수함수와 로그함수 | 그래프와 역함수 관계, 지수·로그 모델링 | 12대수01-06~08 |
| Ⅲ. 삼각함수 | 일반각과 호도법, 삼각함수의 뜻, 그래프, 방정식과 부등식 | 12대수02-01~02 |
| Ⅳ. 삼각함수의 활용 | 사인법칙, 코사인법칙, 삼각형의 넓이 | 12대수02-03 |
| Ⅴ. 등차수열과 등비수열 | 등차수열과 합, 등비수열과 합 | 12대수03-01~03 |
| Ⅵ. 수열의 합, 수학적 귀납법 | ∑, 여러 가지 수열의 합, 귀납적 정의, 수학적 귀납법 | 12대수03-04~07 |

## 각 차시의 구성

질문하기(핵심 질문, 배우기 전 예상) → 탐색하기(탐색 도구, 사실적 질문) → 개념화하기(개념적 질문, 나의 일반화, 멘토 피드백, 교사용 일반화, 개념 정리) → 적용과 전이(채점되는 적용 문제 3개, 논쟁적 질문, 전이 과제) → 성찰하기

## 실행

설치나 빌드가 필요 없는 HTML 파일 하나(`index.html`)입니다. 수식 표시 도구(KaTeX, MathJax)가 파일 안에 들어 있어 크기가 약 2.7MB입니다.

## 저장과 개인정보

- 학습 기록은 `algebra-inquiry-lab-v1` 이름으로 이 기기의 브라우저에만 저장되며, math1의 기록과 섞이지 않습니다.
- G-Man 멘토 API 키 설정(`gman-mentor-key-v1`)은 같은 도메인의 math1과 함께 씁니다. 한 번 넣으면 두 앱에서 모두 작동합니다.
- G-Man 멘토는 Claude(Anthropic), ChatGPT(OpenAI), Gemini(Google) 등 여러 회사의 API 키를 받습니다. 키 모양으로 회사를 자동으로 알아보고, 그 키로 쓸 수 있는 모델을 자동으로 고릅니다. 사용 방법은 앱의 ‘G-Man 멘토 그림 설명서’(#mentor)에 있습니다.
- 자세한 조항은 [PRIVACY.md](./PRIVACY.md)에 있습니다.

## 내용의 출처

- 교육과정: 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정 (대수)
- 교과서: 동아출판 〈대수〉 교과서의 단원 구성과 쪽수, 일부 탐색 상황(소리의 크기 프로젝트, 멸종 위기 곤충, 공학 도구 탐구, 다각수, 프랙털 카드, 벽돌 피라미드). 차시마다 출처를 표시했습니다.
- 적용 문제 63개는 모두 성취기준을 바탕으로 새로 만든 자체 제작 문항입니다.
